Pending Samples
===============

Pre-register geographical metadata for samples that have not yet arrived in MIMOSA.
When a sample with the matching ID is imported, the metadata is applied automatically.
Unmatched entries expire after 30 days (configurable — see :doc:`configuration`).

Navigate to **Pending Samples** in the sidebar (admin only).

.. note::

   For samples already in MIMOSA, edit metadata from the **Samples** page — see :doc:`samples`.

Adding entries
--------------

- **Single entry** — click **Add entry**, fill in the Sample ID and at least one of PostCode, Hospital, or coordinates, then save.
- **Bulk upload** — click **Download template**, fill in the spreadsheet (one row per sample), and drag-and-drop it back onto the page.  Rows with missing required fields are flagged in a preview before you confirm.
